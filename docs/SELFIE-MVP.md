# Selfie Remote v0.1.6

Sony αのBluetoothリモコン機能を使う、自撮り用Androidアプリ。
Sebastian Staacksの[α-Remote](https://github.com/Staacks/alpharemote)をベースにしたGPL-3.0の改変版です。Sony公式アプリではありません。

## 操作

1. 「カメラ接続」でBluetoothと通知の権限を許可し、カメラとペアリングする。
2. カメラのBluetoothリモコンを有効にし、AFを設定する。連写時間を使う場合はカメラを連続撮影モードにする。「1枚」では単写にする。
3. SELFIE画面でSTARTを押して、スマホを隠し、撮影位置へ移動する。
4. カウントダウンが終わってから半押し・AF。新しい合焦通知を受けたら全押しを保持し、全押し→半押しの順に解除する。
5. 次のカウントダウンへ進む。画面と通知のSTOPで終了できる。

## 確定した設定

| 項目 | 選択肢 | 初期値 |
| --- | --- | --- |
| 待機 | 3 / 5 / 10秒 | 5秒 |
| 撮影 | 1枚（全押し100ms） / 0.5 / 1 / 2秒 | 1秒 |
| 試行回数 | 1 / 5 / 10 / ∞ | 5回 |
| カウントダウン音 | ON / OFF | ON |
| AF期限 | 3秒固定 | 3秒 |

「1枚」はカメラの単写設定が前提。連写設定で複数枚撮れてもアプリで補正しない。
AFタイムアウトはシャッターを解除して、エラー音を鳴らし、その回をスキップする。
**失敗も1回の試行に数える**。例えば5回設定で2回AFに失敗すると、撮影操作は3回。
表示する撮影操作回数は、カメラ内の画像枚数を表すものではない。

音OFFはカウントダウンのみ。AF失敗音・終了音は引き続き鳴らす。
音はServiceのToneGeneratorからアラーム音量で出す。アラーム音量ゼロや端末の通知制限によって聞こえない場合はある。
各秒に短音、最後の1秒に二連音、AF失敗に異なる音、ループ完了に長めの音を使用。
音量・カメラのAF・ドライブモードは撮影開始前に確認する。

## 実装

- SELFIE・カメラ接続・取説・アプリ情報と下部タブをCompose / Material 3に統一した。既存Fragmentナビゲーションと権限・ペアリング処理は維持する。
- UIは表示用状態とイベントだけを扱い、Fragmentが既存Service / ViewModelへ接続する。SELFIEの12状態、接続の8状態、取説・アプリ情報の両スキンの通常／ダーク`@Preview`はカメラ操作・Service起動・設定保存を行わない。
- 画面はSELFIE・カメラ接続・取説・設定の4つ。設定には外観の切り替えとアプリ情報をまとめる。接続画面には権限、登録・解除、接続ヘルプを残す。
- 取説は4ステップと撮影直前AFの図、折りたたみ式FAQで構成し、通信なしで読める。AF失敗・音・STOP・切断・カメラ設定の案内を掲載する。
- アプリ情報はアプリ名・バージョン・クレジット・GPL案内と元／改変プロジェクトへのリンクに整理する。GPL-3.0全文をAPK内に同梱し、オフラインのダイアログで表示する。
- 通常リモコン、カスタムボタン、物理キー割り当て、通知ボタンサイズ、Broadcast controlを利用者向け機能から外す。
- 通知には接続状態、撮影中の進行状況とSTOPを表示する。通常撮影・録画ボタンは表示しない。
- 上流由来の未使用UIソースと汎用Action Sequenceは互換用に残るが、ナビゲーションやServiceコマンドからは通常操作を起動できない。
- 自撮り状態機械は `selfie/SelfieController.kt` に分離し、`AlphaRemoteService` が所有する。
- 上流 `TRIGGER_ON_FOCUS` の半押し・全押し・解除ステップを使用する。合焦待ちは自撮りControllerで3秒の期限を設ける。
- カウントダウン開始時には半押ししない。キャッシュされた合焦状態からは撮影しない。
- 各サイクル終了後に次を実行し、無限撮影でも巨大なActionStepリストを作らない。
- Handlerの予約は常に1個。STOPと予約コールバックはServiceの同じロックを使い、取り消し済みコールバックも世代番号で無効化する。
- 起動から終了まで既存のPARTIAL_WAKE_LOCKを保持する。画面OFFとActivity終了はシーケンスを止めない。
- STOPは予約と既存Pending Actionを消し、全押し・半押し・その他のボタンとjogを解除し、WakeLockを解放する。
- 接続が失われたら停止して通知する。再接続だけでは再開しない。STARTを再度押す。
- Serviceの撮影コマンドはSELFIE START / STOPのみ。旧通常リモコンと詳細シーケンスのIntentは実行しない。
- 設定は既存DataStoreで保存し、復元が終わってからSTARTを有効にする。
- `CameraBLE.kt` に変更を加えない。物理的に接続が切れた後の解除コマンドはカメラには送れないため、端末側の進行停止と再開防止を保証する。

## UIの調整

- 「設定」→「外観」→「スキン」でシンプル／kawaiiを選ぶ。初期値はシンプルで、v0.1.5の見た目を維持する。kawaiiはピンク・ラベンダー、太い文字、丸い部品、小さなハートと星の装飾を使う。
- スキンは撮影設定と別のDataStoreキーに保存し、4画面と下部タブへ反映する。通常／ダークは端末の設定に合わせる。撮影中の状態やカメラ設定には影響しない。
- 両スキンの共通の色と文字は `ui/selfie/SelfieTheme.kt`、余白・角丸・選択UIは `ui/components/SelfieComponents.kt` で定義する。
- SELFIEの状態Previewは `SelfiePreviews.kt`、他の3画面は `ui/components/AppPreviews.kt` をAndroid StudioのSplit / Designで開く（PreviewはAPI 36）。
- SELFIEは両スキン×通常／ダーク×12状態の48通りと小画面・大きな文字の2通り。SELFIEのPreviewは未接続・待機・カウント・AF・撮影・AF失敗・終了・停止・切断・復元待ち・無限撮影・スキップあり終了を含む。小画面／大きな文字のPreviewも用意する。
- 自動テストではAPI 36のNative Graphicsで両スキン×通常／ダークの28枚のCompose画面画像を `app/build/outputs/ui-previews/` に生成する。画像はGit管理対象外で、実機画面やMacのIDE Previewと区別する。
- 各Previewは表示用サンプルと空のイベント処理を使う。実カメラ操作・ペアリング・Service・保存は実行しない。取説の折りたたみのみローカルに操作できる。
- カウントは「AF開始まで」、進捗は「試行」と表示する。撮影中のSTOPは設定や状態のスクロール領域の外に置く。
- 画面ホストのXML、システムのペアリング画面、既存の確認ダイアログと通知RemoteViewsは維持する。

## ビルド

Android StudioまたはJava 21 / Android SDK 37.0を使う。
APKのJava互換性は17のまま。Android 16相当のRobolectric起動テストにはJava 21が必要。Android 12（API 31）以上が必要。
SDK Managerではパッケージ名 `platforms;android-37.0` を選ぶ。
`local.properties` に `sdk.dir` を設定するか `ANDROID_HOME` を設定する。
MacのAndroid StudioでCompose Previewを調整し、実機配布APKのビルドと署名は既存の鍵があるN100で行う。端末固有のセットアップ手順はGit管理対象外のローカルファイルに保存する。

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

デバッグAPKは元アプリと別のapplicationId `cc.yukino.selfieremote` でインストールできる。
アプリ名は暫定のSelfie Remote。配布用署名と正式名称の決定は別途行う。

## 実機で確認する項目

自動テストはシーケンスの論理を検証する。BLEとSony α本体の挙動は実機で確認する必要がある。
Pixel 10 Proで**5秒待機・5枚撮影はユーザー確認済み**（Compose移行前、使用APK版は未記録）。網羅的な確認と、Compose版APKの実機確認は未完了。以下は詳細条件ごとのチェックであり、5秒・5枚の報告から推測して完了にしない。
このリストを確認するまではMVPの完成判定とmainへのマージを行わない。

- [ ] Android端末とカメラの機種・OS・ファームウェアを記録する。
- [ ] 「カメラ接続」でペアリングでき、SELFIEの1回撮影で半押し・全押しが動く。
- [ ] カウントダウン中にフレームへ入っても、その時点ではAFしない。
- [ ] カウント終了後にAFし、合焦通知後にだけ撮影する。
- [ ] 前後に移動しても、各サイクルでAFを取り直す。AF-S / AF-Cは使う設定で確認する。
- [ ] 合焦できない被写体では3秒で半押しを解除し、撮影せずスキップする。
- [ ] カメラの単写設定で「1枚」の100ms全押しが安定して1枚撮れる。
- [ ] カメラの連写設定で0.5 / 1 / 2秒の保持が機能する。
- [ ] 1 / 5 / 10回で終わり、AF失敗も回数に数える。
- [ ] ∞で継続し、カウント・AF・撮影中すべてでSTOPが働く。
- [ ] カウント音OFFでも失敗音と終了音は鳴る。
- [ ] アプリを背景へ移動、画面OFF、画面を閉じた場合も動く。
- [ ] ロック画面の通知からSTOPできる。
- [ ] カメラ電源OFF・Bluetooth OFFで止まり、復帰しても自動撮影しない。
- [ ] STOP / 終了 / 切断でWakeLockと押下状態が解放される。
- [ ] 設定変更後にアプリを再起動しても前回値に戻る。
