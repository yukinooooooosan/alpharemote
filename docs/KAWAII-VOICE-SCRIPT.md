# kawaiiモード 音声台本 v0.1

kawaiiモードで流す合成音声の台本と生成ルール。
プリクラ機のアナウンスのように、明るく、はしゃいだ声で撮影を盛り上げる。

## 前提

- スマホはカメラの横に置き、画面を自分のほうへ向ける。2〜3m離れて声を聞く。
- kawaiiモードは **5回・1枚撮り固定**。待機は **1回目だけ10秒、2回目以降は5秒**。AF失敗も1回に数える。
- 声は演出だけに使う。半押し・全押しのタイミングを声の再生で待たせない（鳴らしっぱなし）。
- 声の再生とポーズ・褒め言葉の抽選は撮影Service側で行い、画面と声が必ず同じIDを使う。
- 音声ファイルが無い場合は、今の電子音（ToneGenerator）にフォールバックする。

## タイムライン

声どうしが重ならないように、各合図の長さに上限を設ける。

### 1回目（待機10秒）

| 時刻 | 合図 | クリップ | 上限 |
| --- | --- | --- | --- |
| 0.0秒 | START | `kw_intro` | 2.5秒 |
| 3.0秒 | ポーズ前置き | `kw_pose_lead_first` | 0.9秒 |
| 4.0秒 | ポーズ | `kw_pose_NN` | 2.0秒 |
| 7.0秒 | 3 | `kw_count_3` | 0.7秒 |
| 8.0秒 | 2 | `kw_count_2` | 0.7秒 |
| 9.0秒 | 1 | `kw_count_1` | 0.7秒 |
| 10.0秒 | AF開始 | `kw_cheese` | 1.0秒 |
| 合焦後 | 撮影 | `kw_shutter`（効果音） | 0.5秒 |

### 2回目以降（待機5秒）

| 時刻 | 合図 | クリップ | 上限 |
| --- | --- | --- | --- |
| 0.0秒 | 前の回の撮影直後 | `kw_praise_NN` | 0.9秒 |
| 1.0秒 | ポーズ | `kw_pose_NN`（5回目は先に `kw_last` ） | 0.9秒 |
| 2.0秒 | 3 | `kw_count_3` | 0.7秒 |
| 3.0秒 | 2 | `kw_count_2` | 0.7秒 |
| 4.0秒 | 1 | `kw_count_1` | 0.7秒 |
| 5.0秒 | AF開始 | `kw_cheese` | 1.0秒 |
| 合焦後 | 撮影 | `kw_shutter`（効果音） | 0.5秒 |

- 合図は撮影制御の1秒ごとの通知に合わせて鳴らすため、時刻は整数秒にそろえる。
- 2回目以降は詰まっている。ポーズが0.9秒に収まらない場合は、2回目以降の待機を6秒にする案を検討する。
- 5回目の前は `kw_last`（ラスト1枚！）を褒め言葉の代わりに流し、その後にポーズを言う。
- 最後の撮影のあとは褒め言葉の代わりに `kw_done` と `kw_shots_N` を続けて流す。

### AF失敗のとき

AF失敗はピント待ち3秒の期限で起き、その0.4秒後に次の待機が始まる。

| 時刻（次の待機の開始を0秒とする） | 合図 | クリップ | 上限 |
| --- | --- | --- | --- |
| -0.4秒 | AF失敗 | `kw_af_fail` | 1.3秒 |
| 0.0秒 | （褒め言葉の枠。何も流さない） | — | — |
| 1.0秒 | ポーズ | `kw_pose_NN` | 0.9秒 |

- `kw_af_fail` は褒め言葉の枠を使う。1.3秒を超えると次のポーズと重なるので、短く作る。
- 5回目の前にAF失敗した場合も `kw_last` は流さない（`kw_af_fail` と重なるため）。

### 再生のルール

声は1チャンネルだけで再生し、同時に2つ鳴らさない。

- **割り込む合図**：カウント（`kw_count_*`）、`kw_cheese`、`kw_stop`。前の声を止めてすぐ鳴らす。撮影のタイミングと結びついているため。
- **待つ合図**：それ以外。前の声が鳴っていたら、終わるまで待ってから鳴らす。0.6秒以上待たされたら捨てる（遅れて鳴ると画面とずれるため）。
- `kw_shots_N` だけは `kw_done` の後に続けるので、3秒まで待つ。
- 待ちの列は最大2つ（`kw_done` → `kw_shots_N` を続けるため）。あふれたら古いものから捨てる。割り込む合図が来たら待ちの列は空にする。
- 音声ファイルが入っていれば、kawaiiモードでは従来の電子音（カウント音・AF失敗音・終了音）を鳴らさない。切断音だけは残す。

## 生成ルール

### 使うもの

- Google Cloud Text-to-Speech の Gemini TTS（ja-JP対応）。2026年10月時点で Gemini 2.5 Flash / Pro TTS、Gemini 3.1 Flash TTS（Preview）などがある。
- 自然文のスタイル指示で口調を指定できる。`[laughing]` などのタグもあるが、言葉として読み上げられることがあるので、まずスタイル指示だけで作る。
- 女性声の候補：Kore、Zephyr、Leda、Aoede、Callirrhoe。同じ台詞（`kw_intro`、`kw_pose_01`、`kw_praise_01`）で聴き比べて、1つに決める。**全クリップを同じ声・同じスタイル指示で作る。**

### 共通スタイル指示

```text
プリクラ機の案内音声のように話してください。
明るく元気な若い女性の声で、テンション高め。笑顔が伝わる弾んだ声。
語尾は少し伸ばしてかわいく、はきはきと、やや速めに。
台詞以外の言葉、ため息、笑い声は入れないでください。
```

カテゴリごとに、上の指示へ1行足す。

| カテゴリ | 追加の指示 |
| --- | --- |
| カウント | 短く、リズムよく、1語だけはっきり。 |
| ポーズ | わくわくした呼びかけで、元気よく。 |
| 褒め言葉 | 大げさに、驚きと喜びを込めて褒める。 |
| AF失敗 | ちょっと残念そうに、でもすぐ明るく切り替える。 |
| 終了 | 達成感いっぱいに、ねぎらうように。 |

### 書き出し

- 1台詞＝1ファイル。前後の無音を詰める（先頭の無音は50ms以下）。
- モノラル、OGG（Opus）。ファイル名はAndroidのリソース名規則に合わせ、英小文字・数字・`_`だけ（例：`kw_pose_01.ogg`）。置き場所は `app/src/main/res/raw/`。
- 全クリップの音量（ラウドネス）をそろえる。クリップごとに大小がばらつくと、プリクラ感が崩れる。
- 上限秒数を超えたら、言い回しを短くするか、速めに作り直す。
- 生成したモデル名・声・スタイル指示・日付を `docs/KAWAII-VOICE-CREDITS.md` に記録する（作り直し用）。

### ライセンスの確認

このアプリはGPL-3.0で配布する。同梱する音声を第三者が再配布してよい条件かどうかを、生成前にGoogleの利用規約で確認する。確認した内容と日付をクレジットのファイルに残す。

## 台本

「画面」は画面に出す文字、「読み」は合成音声へ渡すテキスト。誤読しやすい語は読みをかなで書く。

### 進行

| `kw_pose_lead_first` | さいしょのポーズは… | さいしょのポーズは〜？ | 0.9秒 |
| `kw_count_3` | 3 | さん！ | 0.7秒 |

### シャッター回数（終了時）

アプリが数えているのは「合焦してシャッターを押した回数」で、カメラに保存された写真の枚数ではない（連写設定・カード容量・書き込みエラーなどで変わる）。
そのため「〜枚撮れた」とは言わず、「パシャッとできた回数」として読み上げる。画面の表示も同じ言い方にそろえる。

| ID | 画面 | 読み |
| --- | --- | --- |
| `kw_shots_5` | 5かい中 5かい パシャッ！ | 5回ぜんぶ、パシャッとできたよ！ |
| `kw_shots_4` | 5かい中 4かい パシャッ！ | 4回パシャッとできたよ！ |
| `kw_shots_3` | 5かい中 3かい パシャッ！ | 3回パシャッとできたよ！ |
| `kw_shots_2` | 5かい中 2かい パシャッ！ | 2回パシャッとできたよ！ |

| `kw_shots_0` | 5かい中 0かい | あれれ、1回もパシャッとできなかった…。カメラを確認してね。 |

## 追加・変更のルール

- IDは一度決めたら変えない。削除したIDは欠番にして再利用しない。画面の文字と声は同じIDで対応させる。
- 追加するときは、この表とアプリの一覧（文字リソース）を同時に更新する。音声ファイルが無いIDは文字だけ表示し、声は鳴らさない。
- 2回目以降に使う台詞は、上限0.9秒に収まる長さにする。
